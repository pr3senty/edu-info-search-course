# Задание 2 

---

## Формулировка задания

Построить обратный индекс для набора текстовых документов, используя **Roaring Bitmaps**.

- **A)** Построить индекс (хотя бы в памяти), позволяющий выдавать документы, для которых верна булева формула о вхождении слов (`AND / OR / NOT`).
- **B)** Для слов применить предварительную обработку:
  - токенизацию,
  - очистку от стоп-слов,
  - стеммирование / лемматизацию.
- **D)** Реализовать индекс в виде **LSM-подобного дерева**.

---

## Решение

- Реализован **обратный индекс** вида:  
  `term → posting list`, где posting list представлен как **Roaring Bitmap**.
- Поддерживаются **булевы запросы** (`AND`, `OR`, `NOT`) с корректной обработкой приоритетов и скобок.
- Индекс хранится в **LSM-подобной структуре**:
  - memtable — в памяти,
  - immutable SSTable — на диске,
  - compaction выполняет слияние posting lists через операцию `OR`.
- Поиск учитывает данные как из memtable, так и из всех SSTable.
- Реализована **интерактивная консольная программа** для работы с индексом.
