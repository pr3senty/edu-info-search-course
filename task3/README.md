# Задание 3

---

## Формулировка задания

Взяв за основу индекс из задания 2:

- **A)** Реализовать поиск по **префиксу**
- **B)** Реализовать поиск по **wildcard** с помощью **k-gram**

---

## Решение

Решение построено на базе **обратного индекса из задания 2**, который использует:

- **Roaring Bitmap** для хранения posting lists
- **LSM-подобное дерево** для хранения и обновления словаря термов

### Поиск по префиксу

Поиск по префиксу реализован через **диапазонное сканирование словаря термов**.

### Поиск по wildcard

Wildcard-поиск реализован с помощью **k-gram индекса**.

- каждый терм разбивается на **k-граммы длины k (k=3)**
- перед построением k-грамм добавляются маркеры границ слова `$`

`KGramIndex` является **вспомогательной структурой**, поэтому он не сохраняется на диск.

После перезапуска программы он **восстанавливается из словаря термов LSM-индекса**.

## Запуск и использование

Для запуска интерактивного режима:

```bash
python main.py
````
