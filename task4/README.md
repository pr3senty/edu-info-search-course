# Задание 4

---

## Формулировка задания

Взяв за основу индекс из задания 2,

### A) Для каждого документа задать дополнительно атрибут даты и искать по диапазону дат, а так же по булевым формулам, содержащим условия на диапазоны дат

---

### B) Пусть у документа присутствуют две даты: начала и окончания жизни (последняя может быть не задана). Реализовать поиск документов,

* **валидных в диапазоне дат**
* **появившихся в диапазоне дат**

---

## Решение

За основу взят **индекс** из задания 2 и расширен поддержкой **параметрических атрибутов (дат)**.

---

### Структура индекса

Ключи в LSM-дереве имеют префиксы:

```
t:<term>        — текстовый термин
d:<date>        — дата документа
s:<start_date>  — дата появления
e:<end_date>    — дата окончания жизни
```

Каждый ключ хранит **posting list** документов в формате **Roaring Bitmap**.

---

### Поиск по диапазону дат

Диапазонный поиск реализован через **range scan** в LSM:

```
lo ≤ key ≤ hi
```

---

### Поддерживаемые предикаты

#### DATE[L,R]

Документы, дата которых находится в диапазоне:

```
L ≤ date ≤ R
```

---

#### APPEARED[L,R]

Документы, появившиеся в диапазоне:

```
L ≤ start_date ≤ R
```

---

#### VALID[L,R]

Документы, **чей интервал жизни пересекается** с диапазоном `[L,R]`.


```
start_date ≤ R  AND  (end_date is None OR end_date ≥ L)
```
